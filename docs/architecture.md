# Архитектура

## Поддерживаемая страница

Дополнение Firefox использует Manifest V3 и боковую панель. Поддерживаются английские личные формы на origin `https://evisa.gov.vn` с путём `/e-visa/foreigners` или `/e-visa/foreigners/<идентификатор>`, с необязательным завершающим слешем. Идентификатор состоит из букв, цифр, `_` и `-`; query и hash допускаются. Правило задано в [route.js](../extension/shared/route.js).

Перед заполнением или экспортом проверяются маршрут и структура английской формы. Работа выполняется только в верхнем frame. Вход, предварительные подтверждения, переходы по шагам, отправку заявления и оплату выполняет пользователь.

## Сеанс

Сайдбар фиксирует активную вкладку при начале операции и открывает port `evisa-filler` в frame 0. Сеанс принимает соединения только от страницы сайдбара этого дополнения. Команды содержат идентификатор запроса `runId`.

Сначала `probe` проверяет страницу и возвращает `documentId`. Команда `start` передаёт этот идентификатор, проверенные данные и выбранные изображения. Команда `export` запрашивает чтение. Заполнение и экспорт не выполняются одновременно. `stop` и `resume` относятся к активному заполнению владельца соединения.

Заполнение передаёт события `progress`, `paused` и терминальные `completed`, `cancelled`, `failed`. Экспорт возвращает `exported` с данными и предупреждениями. Ошибки протокола содержат статические коды. Смена исходного URL или документа, закрытие страницы и потеря соединения прекращают дальнейшую работу с документом.

## Заполнение

1. Проверяется поддержка формы; пустые значения отмечаются как пропущенные.
2. Дополнение ждёт окончания видимой обработки изображений. Выбранные фотографии загружаются последовательно через нативные file inputs. Подтверждением служит новый загруженный preview или появление паспортного диалога.
3. Открытый диалог сайта вызывает паузу. Пользователь завершает действие на сайте и нажимает «Продолжить». Если диалог остаётся открытым, заполнение остаётся на паузе.
4. Управляющие поля заполняются перед зависимыми; списки заменяются после своих переключателей. Неуспешное родительское действие блокирует только зависимые действия.
5. Значения считываются после записи и повторно перед завершением. В конце проверяется и устанавливается галочка **Committed to declare temporary residence according to the provisions of Vietnameses laws**.

Дополнение не выполняет OCR и не требует пары фотографий или подтверждения результата распознавания. Допустима загрузка одного изображения. Ошибка загрузки отражается в отчёте и не блокирует JSON. Новое уведомление сайта об отказе завершает ожидание загрузки; известное сообщение о script tag имеет отдельную причину.

Методы DOM используют штатные inputs, events, варианты выбора и элементы управления строками. Код не вызывает внутренние функции сайта, не использует framework store и не отправляет прямые запросы к визовому API. Контекст операции проверяется перед каждым изменением DOM и после асинхронных ожиданий.

Поля без значений в JSON не сохраняются и не восстанавливаются. Автоматические изменения сайта в них не считаются ошибками дополнения. Заданные значения проверяются: несовпадение при чтении является ошибкой.

## Результаты и остановка

| Статус | Значение |
| --- | --- |
| `filled` | Значение записано и подтверждено |
| `unchanged` | Текущее значение уже совпадает с заданным |
| `skipped_empty` | Значение не задано |
| `skipped_dependency` | Не выполнена зависимость или действие не началось до остановки |
| `error` | Запись, чтение, загрузка или операция не подтверждены |

Журнал группирует ошибки выше успешных и пропущенных записей. «Подтверждено» отображается зелёным, ошибки красным, пропуски нейтральным цветом. Оба журнала используют общие стили; открытые группы сохраняются при обновлении отчёта. Завершение с ошибками имеет предупреждающий цвет и количество ошибок в сообщении.

Остановка отменяет дальнейшие действия и освобождает наблюдатели и ожидания. Она не откатывает форму и не отменяет запросы, уже отправленные самим сайтом. Поздняя реакция сайта может изменить страницу. Завершённый запуск означает завершение попыток заполнения; готовность заявления проверяет пользователь.

## Данные и разрешения

В манифесте указаны `activeTab`, `downloads` и host permission для `https://evisa.gov.vn/*`. Дополнение не использует постоянное хранилище, телеметрию или внешние сервисы. Файлы и значения находятся в памяти; очистка и закрытие сайдбара удаляют его данные. Изображения, переданные сайту, и экспортированный файл остаются у получателей.

Для изображений проверяются диапазон 10 КиБ–2 МиБ включительно, JPEG/PNG и возможность декодирования. Исходные байты не изменяются. Сайт может отклонить файл после локальной проверки.

Отчёт заполнения содержит пути, названия, статусы и статические причины без значений анкеты. Метаданные вкладки исключают query и hash. Значения передаются в сайдбар для явного экспорта и включаются в выбранный пользователем файл. Временный Blob URL освобождается после завершения или отмены сохранения.
