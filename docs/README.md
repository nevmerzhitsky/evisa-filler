# Документация

Документы описывают текущую реализацию. Версия указана в [манифесте](../extension/manifest.json).

- [README проекта](../README.md): установка, заполнение и экспорт.
- [Контракт JSON](json.md): значения, списки, проверка и правила экспорта.
- [Архитектура](architecture.md): компоненты, сеанс, DOM, ошибки и данные.
- [Разработка и проверки](development.md): тесты и проверка в Firefox.

Полный перечень полей определён в [JSON Schema](../schema/application.schema.json). [Минимальный](../examples/minimal.json) и [расширенный](../examples/extended.json) примеры содержат вымышленные данные.
