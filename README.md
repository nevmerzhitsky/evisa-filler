# E-visa filler

Расширение Firefox для заполнения английской личной анкеты на `https://evisa.gov.vn/e-visa/foreigners` и сохранённых заявлений по ссылкам `https://evisa.gov.vn/e-visa/foreigners/<идентификатор>?email=...`. Работает из сайдбара: заполняет форму из локального JSON и сохраняет текущую форму в JSON.

## Установка

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Load Temporary Add-on / Загрузить временное дополнение** и выберите [extension/manifest.json](extension/manifest.json).
3. Откройте английскую личную форму на сайте. Самостоятельно пройдите предварительные подтверждения и вход, если он нужен.
4. Откройте **E-visa filler** через меню боковых панелей Firefox.

Сборка и установка npm для использования не нужны. После обновления файлов перезагрузите дополнение через `about:debugging`, обновите вкладку формы и откройте сайдбар заново. После перезапуска Firefox временное дополнение загружается повторно.

## Заполнение

Выберите один JSON и нажмите **Заполнить анкету**. Для начала можно использовать [минимальный](examples/minimal.json) или [расширенный](examples/extended.json) пример с вымышленными данными. [Контракт JSON](docs/json.md) описывает поля и правила проверки.

Фотографии необязательны. Можно отдельно выбрать портрет, страницу паспорта или оба файла: JPEG/PNG, от 10 КиБ до 2 МиБ включительно. Фотографии загружаются перед JSON. Если сайт открывает диалог, завершите действие в нём и нажмите **Продолжить**. Подтверждение OCR не требуется.

В конце автоматически отмечается **Committed to declare temporary residence according to the provisions of Vietnameses laws**. Проверьте значения и результат на сайте. Переходы по шагам, отправку заявления и оплату выполняйте самостоятельно.

## Управление и результаты

- **Остановить** прекращает дальнейшие действия. Уже внесённые значения остаются; отправленные сайтом запросы не отменяются.
- **Продолжить** возобновляет заполнение после действия в открытом диалоге сайта.
- **Очистить** удаляет выбранные файлы и отчёт из памяти панели, сохраняя изменения на сайте.
- Кнопки показываются по состоянию: при заполнении доступна остановка, при паузе продолжение и остановка.

Сводка показывает подтверждённые значения, ошибки и пропуски. **Подробный журнал** свёрнут по умолчанию; группы ошибок находятся сверху и раскрываются отдельно. Их раскрытие сохраняется при обновлении отчёта. Предупреждения экспорта находятся в отдельном журнале с тем же оформлением.

Закрытие сайдбара удаляет его данные; после открытия файлы нужно выбрать снова. Данные не сохраняются в постоянном хранилище и не передаются внешним сервисам. Выбранные фотографии отправляются визовому сайту только при запуске заполнения.

## Сохранение формы

Нажмите **Сохранить форму в JSON** в отдельной секции внизу сайдбара. Предварительно выбирать JSON не нужно. Откроется диалог сохранения файла `evisa-YYYY-MM-DD.json` с текущей локальной датой компьютера.

Экспорт сохраняет текущие значения и пустые поля с [исключениями для неактивных разделов](docs/json.md#экспорт). Некорректный черновик сохраняется с предупреждениями; перед импортом ошибки нужно исправить. Фотографии и юридическая галочка в JSON не входят. Отмена диалога сохранения не считается ошибкой.
