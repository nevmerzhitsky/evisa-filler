# Примеры JSON

Оба файла содержат вымышленные данные и демонстрируют структуру частичного JSON. Они не подтверждают полноту анкеты или пригодность данных для подачи.

[`minimal.json`](minimal.json) показывает несколько одиночных полей и полную запись предыдущей поездки. [`extended.json`](extended.json) показывает все поддерживаемые группы и списки. Значения `Example option` и `Example nationality` являются условными заполнителями: замените их точными английскими подписями доступных вариантов сайта.

Правила типов, сопоставления вариантов и замены списков описаны в [контракте JSON](../docs/json.md). Расширенный пример требует замены вымышленных данных перед заполнением.
